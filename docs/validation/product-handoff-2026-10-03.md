# Knowledge → Agent handoff review · 2026-10-03

This Product Design review follows a four-note, six-relation synthetic Vault in the local browser preview. The user task was to inspect a note, attach an exact local excerpt, and draft a question without losing sight of its source. The existing black HUD and explicit Send boundary remain the visual and interaction baseline.

1. **Find and inspect a note — usable, with unnecessary scrolling.** The selected Project Alpha note, local excerpt, and `[S1]` basket were clear, but the search list showed only about two results despite a tall viewport. [Explore capture](product-audit-2026-10-03/02-explore.jpg).
2. **Open Agent from the excerpt — blocked before the change.** At the default 1324×1244 layout, Agent covered roughly half the Knowledge browser, including search results and excerpt controls. The exact snapshot was still available inside Agent, but comparing it with the original pane required moving the window. [Default handoff before](product-audit-2026-10-03/05-default-draft.jpg).
3. **Review and draft — clear after the change.** The same handoff now places an untouched default Agent window to the right when both panes fit. Search, local excerpt, staged `[S1]` range, draft, and Send remain visible together. On a tall viewport the search list shows all four synthetic results. Browser geometry measured an 86px gap between the source pane and Agent; Send was not invoked. [Handoff after](product-audit-2026-10-03/06-source-agent-side-by-side.jpg).
4. **Choose a task — guarded after the change.** Previously, Ask Agent inserted “answer my question:” with no question and enabled Send. It now opens an empty, focused draft with a specific-question placeholder; Send stays disabled until the user enters text. Summary and Compare still supply complete directives to an empty draft, and neither overwrites an existing unsent question. [Question-required capture](product-audit-2026-10-03/09-question-required.jpg).
5. **Resize — usable with a narrow-screen limit.** At 1280×720, the source pane and Agent still have a 68px gap; each pane scrolls internally without page-level horizontal overflow. At 980×720, side-by-side space is insufficient, so the default Agent position is used and the exact `[S1]` snapshot remains inspectable in its source disclosure. Returning to the tall viewport restores the full Agent size and right-side placement. [1280 capture](product-audit-2026-10-03/07-1280-draft.jpg) · [980 capture](product-audit-2026-10-03/08-980-draft.jpg).

The layout change applies to the Knowledge → Agent action only; ordinary window opening and viewport resizing do not opt into it. It remembers its automatic placement across viewport changes and reloads, while a manually moved or resized Agent window keeps the user's bounds. Settings → Interface → Window Layout still restores defaults. Increasing the search list height is limited to viewports at least 900px tall, leaving short-screen behavior unchanged. Draft suggestion is suppressed only for the open-ended question action; attached excerpts remain local until explicit Send.

The accessible tree exposed the source list, its line-numbered disclosure, the draft field, and Send as distinct controls; focus moved to the draft after the handoff. This checks the local keyboard path, not screen-reader usability or WCAG conformance. Screenshots cannot establish target size, contrast in all themes, or physical touch behavior. The preview used synthetic files and a local simulator; no external Agent request or personal Vault content was sent.

Validation: 643/643 frontend tests, ESLint, format contract, and production build passed. Browser UI checks confirmed disabled Send for an empty question, enabled Send after writing a question, retained unsent text on Summary, and a complete Summary directive when the draft was empty. Browser console had no warnings or errors during the responsive check. The production conversation directory remained empty. Device-specific Windows 10, touch, DPI, lock/sleep, and real-provider checks remain part of hardware acceptance.
