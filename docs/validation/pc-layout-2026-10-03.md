# PC layout review — 2026-10-03

The Knowledge → Agent handoff was checked in the isolated browser preview with
four synthetic notes. No prompt was sent to a provider. The previous floating
Agent position covered the Knowledge browser at 1366 and 1920 pixels. The
updated placement measures the Knowledge browser and the visible right rail
after Agent opens, then uses the available center width. Ordinary default
windows now reflow with a changed viewport; manually positioned windows keep
their coordinates until they need clamping to remain on screen.

No viewport in the matrix had page-level horizontal or vertical overflow. At
1024 pixels there is insufficient room for three usable columns, so Agent
covers the Knowledge browser while leaving a 24-pixel gap before telemetry.
At 1280 × 800 and 1366 × 768 the Knowledge browser's content exceeds its
height; its own scrollbar now exposes the bottom actions. The Agent draft and
Send control stayed visible. Toggling telemetry at 1280 pixels expanded Agent
from 538 to 738 pixels and restored it to 538 pixels when the rail reopened.

The default Agent window moved from x=287, width=742 at 1280 × 800 to x=468,
width=1020 at 1920 × 1080 after a viewport change. The Explorer and Settings
surfaces were also inspected at common desktop widths; their content remained
inside the viewport, with internal scrolling where needed. State tests cover
compact handoff, viewport changes, custom positions, persistence, and rail
measurements.

Validation on this change: 646 frontend tests passed; lint, format contract,
and production build passed. Browser measurements were taken after the layout
settled, and the captured page had no console warnings or errors.
