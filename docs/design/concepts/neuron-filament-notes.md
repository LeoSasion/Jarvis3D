# 球体与 3D 共用枝条材质

2026-09-10。用户要求把[球体参考](3d-neuron-sphere-concept.png)和[空间神经元参考](3d-neuron-depth-concept.png)一起研究，重点是沿路径变化的粗细，以及连线本身的透明质感。

两张参考共同使用较宽的根部、逐渐收细的末梢、透明的暖色线体和局部窄高光。球体靠前后球壳的明暗差表达通透；空间图靠前景主枝、远处细枝和不同深度的交错表达纵深。这些形态共用材质，深度参数按视图保留。

## 实现

- 继续使用朝向相机的分段带状几何。每段仍是两个三角形，没有增加管道截面或额外绘制层。
- 每个节点有一个分枝宽度权重，相邻真实树状关系共享端点宽度；直接连接主核的末梢也收细。跨簇轴突两端展开，中间更细。原始关系方向不影响收尖方向。
- 相邻曲线段共用切线，避免增粗后在连接处出现裂缝。透视视图依据深度调整宽度，2D 保留屏幕宽度规则。
- 在片元着色器内模拟圆润截面和随曲线方向变化的窄高光；线体透明程度同时作用于 Core 和 Halo。亚像素细枝使用平均高光，降低整条白线和边缘采样跳变。
- 共用模式下，2D、3D 与待机使用相同的四项材质参数；关闭共用模式后保留独立配置。旧的普通图谱默认关闭新增材质效果。

## 当前预览参数

| 控件 | 数值 | 作用 |
| --- | --- | --- |
| 收尖程度 | 85% | 根部到末梢的宽度变化 |
| 根部增粗 | 5.20 | 主枝靠近神经元核心的宽度倍率 |
| 截面圆润度 | 80% | 横向明暗与窄高光强度 |
| 枝条通透度 | 70% | 细枝与边缘的透明程度；不是直接的 Alpha 百分比 |
| Core 宽度 | 0.95 | 所有分枝宽度的基础倍率 |
| Core 发光 | 1.80 | 保留暖色线体，约束白色高光 |
| 3D 远近明暗 | 85% | 当前预览值；3D 模板仍默认 70% |
| 球体远近明暗 | 90% | 独立于空间布局的前后球壳明暗 |

四项新增控件位于图谱视觉设置的连线区域。2D 与 3D 神经元模板都提供相同的材质参数；独立 2D 模板仍保留较低的 Core 宽度与发光。当前共用预览以 3D 校准值为准。

## 效果与边界

当前主题仍是 NEXUS，使用其橙色连线和浅色高光。相比参考中的金色、景深散焦和绘画式分枝，实现更偏橙红，细枝在 DPR 1 下仍能看出实时采样特征。这是用带状几何模拟体积，不包含真实管道折射或场景透射。

实际分枝数量、主核大小与簇分布来自 808 个笔记；探索仍保留 7809 条完整来源关系，默认 3D 展示 885 条、2D 展示 776 条。球体单独使用 821 条装饰连接。材质没有新增知识节点或关系，也没有改变标签的清晰、无发光样式。
