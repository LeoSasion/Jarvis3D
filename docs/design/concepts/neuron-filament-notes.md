# 球体与 3D 共用枝条材质

2026-09-16 更新。以[球体参考](3d-neuron-sphere-concept.png)和[空间神经元参考](3d-neuron-depth-concept.png)为材质方向，按用户反馈校准发光规律。

每条线沿原有的透明渐变产生自己的明度和色相变化，主体保持修改前的主题橙色。黄色只出现在接近局部亮度峰值的短区间，并快速衰减回橙色；暖白收在最亮光芯，更透明的暗部偏橙红。连线总长度、相机距离与屏幕像素宽度不决定发光色阶；模型中的绝对粗细只提供小幅修正。

## 实现

- 复用沿枝条的透明权重，色阶和强度使用同一条变化路径。未加入按绝对端点距离衰减的计算，因此不会把长线统一压成暗红。
- 主色来自当前主题，在线性颜色空间生成亮度色阶。普通图谱的新增色阶默认关闭，已有自定义参数继续保留。
- 神经元节点是一层边界清楚的多边形细胞，包含浅色亮边、半透明渐变内部和小细胞核。只在约一个像素的轮廓处做抗锯齿，不使用径向渐隐光斑；节点尺寸也不再受旧 Halo 半径影响。
- 普通与末端细胞使用三种主题衍生暖色：当前主题为橙红、亮橙、偏琥珀，按既有真实知识簇分配，同簇同色。小节点在原尺寸上乘以 0.75–1.25 的稳定随机系数，绑定节点 ID；主节点不应用此系数。大小不控制色相，切换视图与悬停不会重新随机。
- 悬停、选中及其直接关联节点切到暖白，交互态发光提高 35%。移走鼠标会清除悬停高亮，仍被选中的节点及关联保持高亮，退出探索后停用交互高亮。主节点身份由知识簇枢纽或球体胞体根节点决定，不依据屏幕大小。
- 随机尺寸和三色在来源或主题变化时一次生成，写入每节点 16 字节的静态属性。当前 808 个节点增加 12,928 字节 GPU 属性数据，不增加材质、绘制批次或每帧随机运算。尺寸变化只小幅影响节点像素覆盖；未据此宣称测得帧率不变。
- 悬停与选中的关联目的地通过常态已有连线导航：在当前可见的边中找确定性的最少跳数路径，共用重合路段，没有现成通路时不补线。直接标记原有带状实例并提高亮度，不创建额外聚焦几何或绘制；常态连线数量、曲线、粗细、透明路径与局部色阶均保持。途经节点只是导航中间点，不新增直接关联含义。
- 导航路段每 2.8 秒在常态亮度的 1.3–1.85 倍之间呼吸，增益作用于最终颜色，不改变色阶的热度输入。路径仅在焦点或可见拓扑变化时计算，呼吸帧只更新亮度参数；减少动态时固定 1.3 倍，移开后恢复常态。
- 导航路径增加电信号：短促暖白亮头与迅速衰减的橙色拖尾，从悬停/选中节点沿现有曲线传向关联端点，在节点与分叉处连续衔接。按累计模型弧长以每秒 240 单位行进，每隔 430 单位发出下一次信号；首波到达前，下游不会自行亮起。反向边会反转距离坐标，选中与悬停使用两个独立传播通道，共用路段不重复增亮。不改变常态色阶、宽度或透明度。
- 信号复用已有带状材质与整体 Bloom，只增加每段 16 字节的距离属性；3D 当前增加 339,840 字节，不增加几何实例或绘制批次。距离只随路线/几何变化更新，动画帧只改变行进距离；无焦点时清除、隐藏时暂停、减少动态时停用移动信号，保留静态聚焦亮度。模型弧长只决定传输进度，不决定常态亮度或色相。
- “路线电信号”有独立开关、传输速度和信号亮度，和旧的“背景信号”分开控制；关闭或亮度为零时保留路线呼吸。默认速度与亮度均为 1 倍，支持共用与独立配置。首波抵达最远目标后，按完整信号间隔回绕计时，避免长时间运行损失精度。
- 原有透明的分段带状几何、根部增粗、末梢收尖和连续切线保持不变。圆润截面及窄高光继续可调；方向高光使用世界坐标，避免随相机转动漂移。
- 节点与连线的本地 Halo 在神经元样式中停用，辉光仅由已有的整体 Bloom 按实际亮度生成。对应的无效 Halo 控件隐藏，已保存值留给其他样式。文字仍在 Bloom 后绘制，不参与发光。关闭整体 Bloom 后，细胞的边界、透明内部和细胞核保持可见。
- 2D、3D 与待机在共用模式下使用同一份特效设置。空间和待机的远近明暗当前均为 0；新 3D 神经元模板也默认关闭这一明暗分层。
- 可选的远近明暗参数对多边形节点的 Alpha 生效，保持色相输入与相机独立。单独将待机设为神经球不会替换普通力布局的探索材质，普通图谱的 Halo 设置仍可使用；待机球体仍只有整体 Bloom。

## 当前预览参数

| 控件 | 数值 |
| --- | --- |
| 发光色阶 | 100% |
| 高光聚焦 | 60% |
| 通透渐变联动 | 100% |
| 收尖 / 根部增粗 / 圆润度 / 通透度 | 85% / 4.40 / 80% / 80% |
| Core 宽度 / 发光 | 0.82 / 1.80 |
| Bloom 增益 / 阈值 / Soft Knee / 半径 | 1.10 / 0.80 / 0.18 / 0.20 |
| 3D 与球体远近明暗 | 均为 0% |

新增控件位于图谱视觉设置的“发光层次”。独立 2D 模板保留较低的基础线宽与发光，共用预览采用 3D 校准值。

## 验证与边界

球体、3D、2D 继续使用同一个 GPU 根节点；曲线实例数分别为 19,704、21,240、18,624，每段仍是两个三角形。新增内容仅为材质计算，没有增加管道网格、渲染通道或知识关系。

当前数据为 808 个笔记、7809 条来源关系；默认 3D 展示 885 条，2D 为 776 条，球体独立使用 821 条装饰连接。拉近和旋转后核对材质输入保持一致；同一条线的渐变不随相机改变。

参考含绘画式分枝和镜头散焦，本轮保留实际图谱布局，没有加入全画面景深、真实折射或场景透射。细枝仍受像素覆盖和抗锯齿影响；这与按屏幕宽度主动改变发光色阶不同。
